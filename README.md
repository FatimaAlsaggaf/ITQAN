# إتقان | ETQAN

**إتقان** هو نظام ذكي يهدف إلى تحسين تجربة الموظفين وتسهيل إدارة الطلبات والمهام داخل بيئة العمل من خلال واجهة حديثة، واضحة، وسهلة الاستخدام.

يركّز المشروع على تقديم تجربة سلسة للموظف والمدير، مع الاستفادة من الذكاء الاصطناعي لتبسيط الإجراءات وتحسين الكفاءة.

## ✨ أهم المزايا

- واجهة حديثة وسهلة الاستخدام
- تصميم متجاوب مع الجوال والتابلت والكمبيوتر
- تجربة مخصصة للموظفين والمديرين
- إدارة الطلبات ومتابعة حالتها
- دعم التفاعل الذكي بالذكاء الاصطناعي
- لوحات تحكم واضحة وتفاعلية
- دعم اللغة العربية
- تصميم Mobile-First
- حركات وانتقالات بسيطة لتحسين تجربة المستخدم

## 🎨 الهوية البصرية

تم تصميم إتقان بأسلوب حديث ونظيف مع التركيز على الوضوح، سهولة الاستخدام، وتجربة المستخدم.

### الألوان الرئيسية

- Primary Purple: `#4C12A1`
- Deep Purple: `#3A0C80`
- Light Purple: `#ECE7F5`
- Lavender: `#DAD0EC`
- Cyan Accent: `#00C1D4`
- Yellow Accent: `#FFCD00`
- Dark Text: `#262626`
- White: `#FFFFFF`

## 📱 Responsive Design

تم تصميم المشروع ليعمل بشكل جيد على:

- Mobile
- Tablet
- Laptop
- Desktop

مع اهتمام خاص بتجربة الجوال لتكون الواجهة خفيفة، واضحة، وسهلة الاستخدام.
